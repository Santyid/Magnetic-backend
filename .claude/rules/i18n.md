# Internationalization (i18n) Rules

## Idiomas Soportados
| Codigo | Idioma | Default |
|--------|--------|---------|
| `es` | Espanol | Si |
| `en` | English | No |
| `pt` | Portugues | No |

## Reglas
1. **TODOS** los strings visibles al usuario deben usar claves de traduccion
2. No hay strings hardcodeados en espanol en el frontend
3. El idioma se persiste en `localStorage`
4. El cambio es instantaneo (sin recargar)

## Archivos
- Traducciones principales: `src/i18n/translations.ts`
- Traducciones landing: `src/i18n/landingTranslations.ts`
- Contexto: `src/i18n/LanguageContext.tsx`

## Uso en Componentes
```typescript
import { useTranslation } from '../i18n/LanguageContext';

function MyComponent() {
  const t = useTranslation();
  return <h1>{t.common.newKey}</h1>;
}
```

## Secciones de Traduccion
| Seccion | Paginas |
|---------|---------|
| `common` | Compartido (cancel, save, loading) |
| `auth` | Login, Register |
| `register` | Register |
| `forgotPassword` | ForgotPassword |
| `dashboard` | Dashboard |
| `dashboardExtra` | Dashboard, TopBanner |
| `profile` | Profile |
| `changePassword` | ChangePassword |
| `admin` | AdminDashboard, Users, AssignProducts |
| `language` | LanguageSelector |
| `metrics` | ProductMetrics, ConnectProductModal |

## Backend: Codigos de Error
El backend retorna **codigos** (no mensajes), el frontend los mapea a traducciones:

```typescript
// Backend retorna:
throw new BadRequestException('INVALID_PRODUCT_CREDENTIALS');

// Frontend traduce segun idioma:
// ES: "Credenciales invalidas. Verifica tu email y contrasena"
// EN: "Invalid credentials. Check your email and password"
// PT: "Credenciais invalidas. Verifique seu email e senha"
```

## Fechas
El frontend usa `toLocaleDateString()` con locale basado en idioma (`es-ES`, `en-US`, `pt-BR`). El backend NO formatea fechas.
